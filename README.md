# XOL汉化补丁

XOL Space Mech Wars 简体中文非官方汉化补丁，版本 V1.0。

**本补丁完全由 ChatGPT 6.1 SOL 翻译和制作。**

## 下载

前往 [Releases](https://github.com/TonisK82/XOL-Chinese-Patch/releases/latest) 下载。

| 版本 | 大小 | 内容 |
| --- | --- | --- |
| 精简版 | 约 1.5 MiB | 菜单、对白、任务目标、选关简报及中文字体；保留原版视频 |
| 完整版 | 约 134.5 MiB | 全部文字汉化和 10 个中文字幕简报视频 |

中文字体已精简，修复对白字幕缺字，调整选关简报字距；章节名称采用“小小的月亮”“伽利略宙域”等最新译名。

## 安装

1. 退出游戏，在 Steam 中右键游戏 → 管理 → 浏览本地文件。
2. 将补丁全部文件解压到游戏根目录，与 `XOL.exe` 同级。
3. 完整版运行 `Install.cmd`；精简版运行 `InstallLite.cmd`。
4. 启动游戏，在语言菜单选择“简体中文”（原 ENGLISH 槽位）。

安装不依赖固定盘符。完整版卸载运行 `Uninstall.cmd`，精简版卸载运行 `UninstallLite.cmd`。

**完整版与精简版切换前，必须先卸载当前版本。** 已安装完整版的用户，请先卸载并恢复原视频，再安装精简版。请保留 `XOL_ZH_Backup` 文件夹，以便恢复。
